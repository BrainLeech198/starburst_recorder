Local-first journal with AI built in: jot a line about today and AI reshapes it into a finished entry. No account, no cloud — every record stays on your device. AI runs on your own model and API key.

## What's new

- **Export only the records you pick** — mix diary entries, quick notes, health intake and finance records in one file for AI or someone else, without exporting the whole library
- **Three formats** — Markdown grouped by date and type, clean plain text, or JSON with every field kept
- **Two entry points** — Data & backup in Settings, and the batch bar in the intake list

## Downloads

| Platform | File |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.2.10-setup.exe` (~95 MB) |
| Android 10+ | `starburst-recorder-0.2.10.apk` (~16 MB, release-signed) |

Android is a sideload build — allow installs from unknown sources. If you had an earlier debug build installed, uninstall it first: this one uses the release key and will not upgrade over it. Storage follows the platform: SQLite on desktop, IndexedDB in the browser and WebView.

## Known limits

0.2.10 is an early build. Finance and Calendar are still placeholders in the app, and the data format may change between releases — export a backup before upgrading.
