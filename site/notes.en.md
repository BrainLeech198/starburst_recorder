Local-first journal with AI built in: jot a line about today and AI reshapes it into a finished entry. No account, no cloud — every record stays on your device. AI runs on your own model and API key.

## What's new

- **Home sits in the middle again** — the mark and title no longer hug the top edge on phones, and the whole block is centred in the viewport
- **Long dialogs stay on screen** — content scrolls inside the panel, so buttons and fields are always reachable
- **Top-bar menus stay on screen** — on narrow phones the Insert / File / Tools menus open against the nearest edge instead of off the left side

## Downloads

| Platform | File |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.2.9-setup.exe` (~95 MB) |
| Android 10+ | `starburst-recorder-0.2.9.apk` (~16 MB, release-signed) |

Android is a sideload build — allow installs from unknown sources. If you had an earlier debug build installed, uninstall it first: this one uses the release key and will not upgrade over it. Storage follows the platform: SQLite on desktop, IndexedDB in the browser and WebView.

## Known limits

0.2.9 is an early build. Finance and Calendar are still placeholders in the app, and the data format may change between releases — export a backup before upgrading.
