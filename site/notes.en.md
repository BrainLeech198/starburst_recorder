A local-first personal recorder with built-in AI: jot down today and AI turns it into a full diary entry. No sign-up, no cloud — everything stays on your device. AI runs on your own model and key.

## What's new

- **Meals open a detail view**: components, grams, total calories and protein, plus any deleted components are listed
- **Meals can be duplicated**: copy one from the menu with the same components and grams, and the name gets a copy suffix
- **Meals now match single foods**: detail, edit, copy and delete all live in the same row menu

## Download

| Platform | File |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.6.3-setup.exe` (~95 MB) |
| Android 10+ | `starburst-recorder-0.6.3.apk` (~16 MB, release-signed) |

Android is sideloaded: allow "install unknown apps". If you previously installed a debug build, uninstall it first (different signature — the upgrade install will fail).
Storage follows the platform: SQLite on desktop, IndexedDB in browsers and WebViews.

## Known limitations

0.6.3 is an early build. Finance and calendar are still placeholder pages, and the data format may change between versions — export a backup of anything you care about before upgrading.
