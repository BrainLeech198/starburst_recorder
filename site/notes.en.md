Local-first journal with AI built in: jot a line about today and AI reshapes it into a finished entry. No account, no cloud — every record stays on your device. AI runs on your own model and API key.

## What's inside

- **Ask AI before you log it** — while adding a food, pick the dish and grams and ask right away whether this portion works; AI sees this portion's macros, what you have eaten today and what is left. Once an item is in the intake list, it is no longer offered for questions
- **Window resets after the keyboard closes** — on Android the interface no longer stays pushed up after typing and dismissing the keyboard; the fix lives in the app shell and covers every input

## Downloads

| Platform | File |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.3.1-setup.exe` (~95 MB) |
| Android 10+ | `starburst-recorder-0.3.1.apk` (~16 MB, release-signed) |

Android is a sideload build — allow installs from unknown sources. If you had an earlier debug build installed, uninstall it first: this one uses the release key and will not upgrade over it. Storage follows the platform: SQLite on desktop, IndexedDB in the browser and WebView.

## Known limits

0.3.1 is an early build. Finance and Calendar are still placeholders in the app, and the data format may change between releases — export a backup before upgrading.
