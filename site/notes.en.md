Local-first journal with AI built in: jot a line about today and AI reshapes it into a finished entry. No account, no cloud — every record stays on your device. AI runs on your own model and API key.

## What's inside

- **Diary** — one slip per day, quick notes on a timeline, read-only paper view, trash and batch actions
- **AI compose** — three tones, nothing is written until you confirm; works with any OpenAI-compatible endpoint, including a model on your own machine
- **Image import** — photograph a handwritten page and let a vision model read it into the editor
- **Weather** — one lookup per day via Open-Meteo, applied only if you accept the result
- **Health** — body profile, TDEE, food library and meals, daily calorie and protein progress
- **Backup** — export Markdown, plain text or full JSON; import merges and walks you through conflicts
- **Bilingual UI** — Chinese and English, light and dark themes, six accent colours
- **Update check** — the app looks for a new release on startup and can download and launch the installer in place

## Downloads

| Platform | File |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.1.0-setup.exe` (~95 MB) |
| Android 10+ | `starburst-recorder-0.1.0.apk` (~16 MB, release-signed) |

Android is a sideload build — allow installs from unknown sources. If you had an earlier debug build installed, uninstall it first: this one uses the release key and will not upgrade over it. Storage follows the platform: SQLite on desktop, IndexedDB in the browser and WebView.

## Known limits

0.1.0 is an early build. Finance and Calendar are still placeholders in the app, and the data format may change between releases — export a backup before upgrading.
