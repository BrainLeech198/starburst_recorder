本地优先的个人记录工具，内置 AI：随手记一句今天，AI 会把它整理成一篇完整的日记。不用注册、没有云端，每一条记录都留在这台设备上。AI 用的是你自己准备的模型和 Key。

## 这一版有什么

- **AI 助手能动手了**：不只是问答。记一笔收支、写一条随记或日记、记睡眠、称重、记摄入，都可以让助手先起草；每次写操作都先给你看预览，点确认才写入，刚写完还能撤销
- **助手有了长期记忆**：偏好、目标、习惯和事实存在本机，在「我的 → 助手 → 长期记忆」里维护；每次对话自动带上，不用重复交代
- **对话不会再丢**：完整对话会保存下来，悬浮球和整页助手共用同一段会话；悬浮球也恢复默认显示
- **收支模块可以用了**：记一笔、选分类、改或删、按天汇总，顶部看本月结余；月栏补上「本月 / 上月」标记和起止日期
- **日期栏统一**：日记、健康、收支的日期控件收进圆角矩形，样式一致
- **更新通道**：「我的 → 版本」可以在正式版和测试版之间切换；测试版只在 GitHub 发布，正式版用户不会收到

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.8.0-setup.exe`（约 95 MB） |
| Android 10 以上 | `starburst-recorder-0.8.0.apk`（约 16 MB，正式签名） |

安卓为侧载安装，需要允许「安装未知来源应用」。之前装过 debug 测试包的，要先卸载再装这一版（签名不同，覆盖安装会失败）。
存储跟着平台走：桌面是 SQLite，浏览器与 WebView 里是 IndexedDB。

## 已知限制

0.8.0 是早期版本，日历仍是占位页；数据格式也可能在版本之间变化，升级前先导出一份备份。助手的长期记忆与对话只存在本机，不进备份。
