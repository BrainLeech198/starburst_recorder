本地优先的个人记录工具，内置 AI：随手记一句今天，AI 会把它整理成一篇完整的日记。不用注册、没有云端，每一条记录都留在这台设备上。AI 用的是你自己准备的模型和 Key。

## 这一版有什么

- **助手可以开新对话了**：不用一段话聊到底——能新建、切换、删除对话，每段对话各自保留上下文；旧的单段对话会自动变成第一段
- **能发图片和文件**：一条消息最多带 3 个附件，图片会先压小，文本文件直接读进对话
- **回答后有推荐问**：每次答完按话题给三条可以点的追问，不想打字就直接点
- **一直在告诉你它在干什么**：等待时显示「正在处理 · N 秒」和当前在查哪一项，不再干等
- **上下文与 token 看得见**：输入框上方显示上下文占用进度、本轮 token 数，以及「已压缩 N 条较早对话」
- **查询更克制**：同一次回答里重复的查询直接复用结果，单轮查询有次数上限，查够了就先回答
- **经济页多了两张图**：本月支出分类占比，以及近半年收支趋势
- **安卓可从手机健康应用导入**：只读读取 Health Connect 里的体重与睡眠，已经记过的日子跳过、不覆盖手记内容

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.9.0-setup.exe`（约 95 MB） |
| Android 10 以上 | `starburst-recorder-0.9.0.apk`（约 16 MB，正式签名） |

安卓为侧载安装，需要允许「安装未知来源应用」。之前装过 debug 测试包的，要先卸载再装这一版（签名不同，覆盖安装会失败）。
存储跟着平台走：桌面是 SQLite，浏览器与 WebView 里是 IndexedDB。

## 已知限制

0.9.0 是早期版本，日历仍是占位页；数据格式也可能在版本之间变化，升级前先导出一份备份。助手对话与长期记忆只存在本机，不进备份。安卓的健康应用导入属于实验功能，尚未做真机验证，读不到时请反馈。
