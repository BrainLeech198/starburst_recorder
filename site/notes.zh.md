本地优先的个人记录工具，内置 AI：随手记一句今天，AI 会把它整理成一篇完整的日记。不用注册、没有云端，每一条记录都留在这台设备上。AI 用的是你自己准备的模型和 Key。

## 这一版有什么

- **日记**：一天一张纸条，随记走时间轴，另有只读纸面视图、回收站和批量操作
- **AI 整理**：三种口气可选，确认后才写入；接口兼容 OpenAI，也可以指向本机模型
- **图片导入**：拍一张手写页，交给视觉模型认成文字送进编辑页
- **天气**：每天查一次 Open-Meteo，结果要你点「填上」才写入
- **健康**：身体档案、TDEE、食物库与套餐、每日热量与蛋白进度
- **备份**：导出 Markdown / 纯文本 / 完整 JSON；导入会合并并逐条处理冲突
- **中英双语界面**：深色与浅色主题、六种主题色
- **检查更新**：启动时自己看一眼有没有新版本，能直接下载并拉起安装程序

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.1.0-setup.exe`（约 95 MB） |
| Android 10 以上 | `starburst-recorder-0.1.0.apk`（约 16 MB，正式签名） |

安卓为侧载安装，需要允许「安装未知来源应用」。之前装过 debug 测试包的，要先卸载再装这一版（签名不同，覆盖安装会失败）。存储跟着平台走：桌面是 SQLite，浏览器与 WebView 里是 IndexedDB。

## 已知限制

0.1.0 是早期版本。应用里的财务和日历还是占位页，数据格式也可能在版本之间变化——升级前先导出一份备份。
