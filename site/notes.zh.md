本地优先的个人记录工具，内置 AI：随手记一句今天，AI 会把它整理成一篇完整的日记。不用注册、没有云端，每一条记录都留在这台设备上。AI 用的是你自己准备的模型和 Key。

## 这一版有什么

- **长辈关怀模式**：「我的 → 长辈关怀」，四档字号（标准 / 大 / 特大 / 超大）把整套界面等比放大；另有加大按钮、高对比、减少动效三个开关，删除这类危险操作要点两次才生效
- **睡眠日记**：健康页可以记就寝、起床和睡得怎么样，时长自动算；删了能撤销，也有独立回收站；备份、导入、单条导出都会带上睡眠
- **每周空腹称重与推算 TDEE**：档案里的 TDEE 改叫「参考 TDEE」；在称重卡里设每周称重日和提醒时刻，到点弹通知；记下体重后，摄入条上多出一条用真实摄入和体重反推的「推算 TDEE」，数据不够就先不画
- **问 ai 一下**：放在「记一笔摄入」下面，五个预设问题一点就发，能接着追问；AI 会读当天的摄入、档案和三条线的数值
- **下载源可选**：版本页可以选 Gitee 或 GitHub 作为更新下载源，选中的先试，失败自动换另一个

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.2.13-setup.exe`（约 95 MB） |
| Android 10 以上 | `starburst-recorder-0.2.13.apk`（约 16 MB，正式签名） |

安卓为侧载安装，需要允许「安装未知来源应用」。之前装过 debug 测试包的，要先卸载再装这一版（签名不同，覆盖安装会失败）。
存储跟着平台走：桌面是 SQLite，浏览器与 WebView 里是 IndexedDB。

## 已知限制

0.2.13 是早期版本。应用里的财务和日历还是占位页，数据格式也可能在版本之间变化——升级前先导出一份备份。
