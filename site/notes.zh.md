本地优先的个人记录工具，内置 AI：随手记一句今天，AI 会把它整理成一篇完整的日记。不用注册、没有云端，每一条记录都留在这台设备上。AI 用的是你自己准备的模型和 Key。

## 这一版有什么

- **日记和随记能手绘插图了**：插图来源多一个「自己画」，画笔、橡皮、颜色、粗细、撤销、清空都有，画完直接作为图片插进记录
- **食物库能挑选导出和导入了**：记录级导出多出「食物库」一类，勾选后和日记、随记、健康记录混在一份文件里；导入同样认这份文件，照片跟着 JSON 一起走，可读格式里会提示照片只在 JSON 中
- **食物照片处理更省内存**：压缩完主动断开原图位图、回收画布，低内存手机保存时不容易被系统杀掉

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.6.0-setup.exe`（约 95 MB） |
| Android 10 以上 | `starburst-recorder-0.6.0.apk`（约 16 MB，正式签名） |

安卓为侧载安装，需要允许「安装未知来源应用」。之前装过 debug 测试包的，要先卸载再装这一版（签名不同，覆盖安装会失败）。
存储跟着平台走：桌面是 SQLite，浏览器与 WebView 里是 IndexedDB。

## 已知限制

0.6.0 是早期版本。应用里的财务和日历还是占位页，数据格式也可能在版本之间变化——升级前先导出一份备份。
