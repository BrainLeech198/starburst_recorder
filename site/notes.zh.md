本地优先的个人记录工具，内置 AI：随手记一句今天，AI 会把它整理成一篇完整的日记。不用注册、没有云端，每一条记录都留在这台设备上。AI 用的是你自己准备的模型和 Key。

## 这一版有什么

- **应用里有公告了**：顶部横幅 + 「我的 → 公告」列表，官方发的东西都能在这看到。紧急公告用红色标出来，点标题展开正文
- **紧急公告会反复提醒**：像「请把之前用过的 API Key 删掉」这种需要动手处理的事，看过也会再提醒，直到你处理完。不处理就容易被划过去
- **邮箱订阅官方频道**：设置页填一个邮箱，重要公告就发到信箱，随时能退订。退订即从服务端删掉，不是打个标记
- **能直接给官方反馈**：设置页写一段话提交，问题、建议、用着别扭的地方都能说。不用注册，不用工单号
- **三个平台都收得到**：网页版、网页版装到主屏幕、安卓、Windows 安装包，用的是同一套接口。**网页版的提醒推送只有浏览器有，所以公告走的是另一条线**——不靠推送，安卓与 Windows 用户一样能收到
- **日记、随记、摄入和单笔收支可扫码分享**：分享码可以保存为图片；从主页扫码时也能选择二维码图片，导入前先预览。
- **数据页新增“清空所有数据”**：包含记录、助手对话及模型/API Key、记忆、技能等偏好，确认时明确列出范围。
- **助手斜杠菜单改为选择技能**：输入 `/` 搜索已启用 Skills，选中后再补充任务。
- **网页版数据导出修复**：浏览器直接启动下载；不支持看图的模型与无法读取的图片会给出明确提示。

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.14.0-setup.exe`（约 96 MB） |
| Android 10 以上 | `starburst-recorder-0.14.0.apk`（约 62 MB，正式签名） |

安卓为侧载安装，需要允许「安装未知来源应用」。之前装过 debug 测试包的，要先卸载再装这一版（签名不同，覆盖安装会失败）。
存储跟着平台走：桌面是 SQLite，浏览器与 WebView 里是 IndexedDB。

## 已知限制

0.14.0 仍是早期版本，数据格式也可能在版本之间变化，升级前先导出一份备份。旧备份仍可直接导入；AI 对话会随备份一起走，带图片附件时会明显变大。安卓的健康应用导入属于实验功能，尚未做真机验证，读不到时请反馈。

**重要：0.13.1 之前导出的备份文件里，AI 密钥是明文的。** 若你曾导出过备份并存到网盘、邮箱或发给别人，请到模型服务后台删除（作废）之前用过的 API Key，再到「AI 设置」里重新填写。0.13.1 起导出时可以加口令加密 `apiKey`，但**只保护以后新导出的文件**，已经导出的旧文件不会自动变安全。

**关于备份里的密钥**：0.13.1 起导出时可以加口令加密 `apiKey`，日记、体重、收支这些不可再生的数据仍是明文——为了一份可再生的字段给整份文件上口令，一旦忘记口令赔进去的是不可恢复的数据。口令留空就是原来的明文导出。

**关于网页版提醒**：要实现「应用关着也能收到提醒」，就必须有一个服务器知道你「几点要提醒」。所以上传的是提醒位（几点、哪一类），**不是提醒内容**——服务器不知道你 8:00 要称重，更看不到你的日程标题、训练项目或日记。

**关于订阅**：邮箱只用于收公告，不做别的，也不会给第三方。退订即从服务端删除。
