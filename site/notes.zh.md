本地优先的个人记录工具，内置 AI：随手记一句今天，AI 会把它整理成一篇完整的日记。不用注册、没有云端，每一条记录都留在这台设备上。AI 用的是你自己准备的模型和 Key。

## 这一版有什么

- **随记也有短编号**：每条随记带上 7 位编号，和日记一样方便指代；旧数据会自动补齐
- **AI 整理后可以接着聊**：生成草稿后继续提要求，每轮都给出完整新稿；手动改过的内容也会带上
- **AI 润色也能对话**：不满意就接着提要求，反复调整到顺眼再替换正文
- **手机更新下载更稳**：Gitee 和 GitHub 两个源各试一次，国内网络下不再卡在 GitHub
- **设置里能清缓存**：一键清掉临时文件和已下载的安装包；日记、随记、健康、收支和 AI 配置都不动

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.2.8-setup.exe`（约 95 MB） |
| Android 10 以上 | `starburst-recorder-0.2.8.apk`（约 16 MB，正式签名） |

安卓为侧载安装，需要允许「安装未知来源应用」。之前装过 debug 测试包的，要先卸载再装这一版（签名不同，覆盖安装会失败）。存储跟着平台走：桌面是 SQLite，浏览器与 WebView 里是 IndexedDB。

## 已知限制

0.2.8 是早期版本。应用里的财务和日历还是占位页，数据格式也可能在版本之间变化——升级前先导出一份备份。
