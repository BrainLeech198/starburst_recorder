本地优先的个人记录工具，内置 AI：随手记一句今天，AI 会把它整理成一篇完整的日记。不用注册、没有云端，每一条记录都留在这台设备上。AI 用的是你自己准备的模型和 Key。

## 这一版有什么

- **每条回答都能动手了**：复制、重新生成、删除这条及之后。重新生成不会丢掉旧回答，用「版本 1/2」左右翻回去比较
- **改一句话就另起一支**：编辑发过的用户消息，保存后从那里分叉出一条新会话，原对话一个字不动；同一组分支在会话列表里直接切换
- **多选与导出**：消息可多选、全选，批量复制、导出或删除；导出支持 Markdown、TXT、JSON 与长图，可选带不带工具轨迹和动作卡片，桌面上直接落进下载目录，安卓会弹系统选择器
- **回答按 Markdown 渲染**：标题、列表、代码块、引用、表格与链接都能正常显示；不用 innerHTML，链接只放行 http(s) 与 mailto
- **能停、能插话、能排队**：生成中可以随时停止，停止不会留下半截回答；回复过程中补一句要求，会在下一步带上；连着发几条会排队逐条发送
- **计划模式**：先给 2–5 步计划，不动手也不弹确认卡；确认后关掉计划模式再执行。开关状态跟着偏好设置一起备份
- **@ 引用记录**：输入框里引用今天 / 昨天 / 最近 7 天，或日记、随记、收支、食物、套餐，把话说准
- **/ 快捷指令**：输入 / 唤出常用问法，直接填进输入框
- **撤销本轮写入**：一条回答里已完成的动作可以一键撤回，没撤掉的会说明是哪几条
- **日期栏不再截断日期**：按这一栏的实际宽度决定相对日与星期要不要让位；字号放大时阈值跟着放大，日期始终完整
- **触控与对齐**：助手卡片的取消 / 撤销、选项与消息操作补到 44px 触控高度；日程页标题栏按钮统一右对齐

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 | `starburst-recorder-0.13.0-setup.exe`（约 96 MB） |
| Android 10 以上 | `starburst-recorder-0.13.0.apk`（约 62 MB，正式签名） |

安卓为侧载安装，需要允许「安装未知来源应用」。之前装过 debug 测试包的，要先卸载再装这一版（签名不同，覆盖安装会失败）。
存储跟着平台走：桌面是 SQLite，浏览器与 WebView 里是 IndexedDB。

## 已知限制

0.13.0 仍是早期版本，数据格式也可能在版本之间变化，升级前先导出一份备份。旧备份仍可直接导入；AI 对话会随备份一起走，带图片附件时会明显变大。偏好设置也在备份里，含接口密钥的那份不要外发。安卓的健康应用导入属于实验功能，尚未做真机验证，读不到时请反馈。
